# DSH Windows 消息提示（测试版）

你不可能一直盯着 Agent。它卡在权限审批、额度不足或其他问题上，你可能一时没发现。这时候，你就需要这个插件了。

为 DeepSeek Harness 桌面版提供 Windows 系统通知：回复完成、需要授权或回答、错误、额度和登录问题。独立社区项目，与 DeepSeek 官方无隶属关系。

**本项目为 alpha 测试版。** 已用 DSH 0.2.2-rc.3 隔离 Web 宿主和合成会话核对事件桥及 Windows 测试通知接口。桌面端的真实回复、授权和额度耗尽尚未端到端验证。npm 包名为 `dsh-xin505-notify`，测试版本使用 `alpha` 标签。

## 提醒行为

- 按宿主的回合结束结果区分完成、失败和停止；完成与失败时均提醒，窗口在前台时静音。已加载的会话有回复内容时，完成提醒展示截断预览；无法读取时退回会话标题或通用文案。主动停止不显示为完成。
- 等待授权、提问或计划审阅时提醒；窗口在前台时静音。通过 DSH 的待处理状态观察，不参与授权或回答。
- 宿主识别到部分额度、认证或限流错误时提醒；这些提醒可能有声音。提供商未映射到受支持错误码时，无法保证识别。
- 设置 › 通用 › 桌面通知提供总开关和测试按钮。开关关闭后，宿主与页面发起的通知均停止。开关保存在 `$DSH_HOME/dsh-xin505-notify/settings.json`，默认 `~/.dsh/dsh-xin505-notify/settings.json`。

## 本地试用

需要 Windows、DeepSeek Harness 桌面版和已允许系统通知的应用。先停用原来的本地 `dsh-desktop-notify`，避免两个插件重复提示；在 DSH 插件管理中选择本目录安装，按宿主提示重启。进入设置 › 通用 › 桌面通知，点击测试按钮。测试按钮显示发送成功只代表 Windows API 接受了请求，不证明横幅已被用户看到。

实际验收应逐项测试：后台正常完成、主动停止、需要授权、提问、常见错误、额度不足、关闭开关、重新启动后保持关闭；再检查与现有插件同时启用时的行为。失败时到 Windows 设置 › 系统 › 通知检查 DeepSeek Harness、通知勿扰模式与横幅权限。

## 隐私和限制

通知可能包含会话标题、授权理由、问题或错误内容，可能显示在通知中心或锁屏。新版诊断日志只记录来源、时间及退出码，不写通知标题或正文；旧版 `~/.dsh/dsh-desktop-notify/toast.log` 已经记录过的内容不会被本版自动删除。通知偏好和诊断日志保留在本机。

- 点击通知目前不能自动切换到相应会话或拉起窗口。
- 页面完全退出后，页面侧事件无法提醒；额度和登录事件只在宿主仍运行时可用。宿主事件缓存有限，页面长时间断开时可能漏掉较早事件。
- 同一会话的多个待处理事项由 DSH 按优先级展示，次级事项可能延后提醒。多窗口尚无跨窗口去重；子代理识别依赖会话目录可用性。
- 通知限流重试次数有限；多窗口、系统通知设置和宿主 API 更新都可能导致漏报或重复提醒。不要将此测试版作为唯一的关键告警渠道。
- Windows Toast 使用 DeepSeek Harness 的 `com.deepseek.dsh` 应用标识。非 Windows 系统不支持。

# DSH Windows 消息提示（测试版）

你不可能一直盯着 Agent。它卡在权限审批、额度不足或其他问题上，你可能一时没发现。这时候，你就需要这个插件了。

为 DeepSeek Harness 桌面版提供 Windows 系统通知：回复完成、需要授权或回答、错误、额度和登录问题。独立社区项目，与 DeepSeek 官方无隶属关系。

**本项目为 alpha 测试版。** 已用 DSH 0.2.2-rc.3 隔离 Web 宿主和合成会话核对事件桥及 Windows 测试通知接口。桌面端的真实回复、授权和额度耗尽尚未端到端验证。npm 包名为 `dsh-xin505-notify`，测试版本使用 `alpha` 标签。

## 提醒行为

- 只要 DSH 宿主仍在运行，主任务完成、失败或被系统中断时就能发送提醒，页面可以关闭。用户主动停止时保持安静。遇到限流后重试成功，会单独提醒任务完成。
- 有页面连接时，插件可根据窗口焦点静音，并提醒仍在等待的授权、提问或计划审阅。翻看已回答的问题不会触发回答提醒。同一宿主下的多个窗口共享通知投递记录。
- 对宿主识别出的额度、凭证、登录过期和限流问题给出对应提示。提供商返回未知错误时，回合失败仍可触发通用提醒。
- 在 **设置 › 通用 › 桌面通知** 可关闭提醒、发送测试弹窗或开启内容预览。新安装和从 alpha.1 升级时均默认只显示状态。之前关闭的总开关会保持关闭。设置保存在 `$DSH_HOME/dsh-xin505-notify/settings.json`，默认位于 `~/.dsh/dsh-xin505-notify/settings.json`。

## 本地试用

需要 Windows、DeepSeek Harness 桌面版和已允许系统通知的应用。先停用原来的本地 `dsh-desktop-notify`，避免两个插件重复提示；在 DSH 插件管理中选择本目录安装，按宿主提示重启。进入设置 › 通用 › 桌面通知，点击测试按钮。测试按钮显示发送成功只代表 Windows API 接受了请求，不证明横幅已被用户看到。

实际验收应逐项测试：后台正常完成、主动停止、需要授权、提问、常见错误、额度不足、关闭开关、重新启动后保持关闭；再检查与现有插件同时启用时的行为。失败时到 Windows 设置 › 系统 › 通知检查 DeepSeek Harness、通知勿扰模式与横幅权限。

## 隐私和限制

默认的系统通知只显示状态。手动开启内容预览后，已加载会话的回复片段、会话标题、授权理由或问题可能显示在横幅、通知中心和锁屏。宿主通过标准输入向本机 Windows 通知进程传递文字。诊断日志记录投递状态，不含通知标题和正文。升级前已经出现在 Windows 通知历史、系统审计日志或旧插件日志中的内容按原有保留策略处理。

- 点击通知目前不能自动切换到相应会话或拉起窗口。
- 退出整个 DSH 宿主会停止投递。授权和提问提醒需要页面观察待处理状态。DSH 同一会话有多项待处理请求时，会按优先级依次显示。
- 回合和带有共享调用标识的待办可跨窗口去重。旧接口产生的个别待办只有窗口内标识，多窗口时仍可能重复。
- 临时故障会触发有界重试。队列位于宿主内存，重启宿主、长时间断连、系统禁用通知或勿扰模式，都可能影响送达或横幅显示。
- Windows 通知使用已安装的 DeepSeek Harness 应用标识。在系统设置中关闭该应用的通知后，插件会尊重这项设置。
